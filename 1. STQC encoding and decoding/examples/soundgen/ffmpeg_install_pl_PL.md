# Instalacja FFmpeg

W tym pliku znajdziesz pełną instrukcję, jak zainstalować FFmpeg na każdym systemie.

### Windows

Aby zainstalować FFmpeg na Windowsie, otwórz aplikację PowerShell i wpisz poniższą komendę:

```powershell
winget install ffmpeg
```

...a następnie poczekaj, aż komenda zakończy działanie

### MacOS

Otwórz Terminal i wpisz:

```zsh
brew install ffmpeg
```

Gdy komenda zakończy działanie, FFmpeg będzie zainstalowany i gotowy do działania!

### Linux

Użyj komendy odpowiedniej dla Twojej dystrybucji:

```bash
# Ubuntu/Debian
sudo apt install ffmpeg
# Fedora/RHEL
sudo dnf install ffmpeg
# Arch
sudo pacman -S ffmpeg
```

### FreeBSD

Użyj poniższej komendy:

```tcsh
pkg install ffmpeg
```

### Android (Termux)

Użyj poniższej komendy:

```bash
pkg install ffmpeg
```
